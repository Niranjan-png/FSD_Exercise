✨ The React Way (With Components)

1️⃣ Write Once, Use Everywhere

Create ONE ProfileCard component = ~15 lines

Use it 3 times = Still just ~15 lines of component code + 3 lines to use it

// Define component ONCE function ProfileCard(props) { return ( <div className="profile-card"> <div className="avatar">{props.avatar}</div> <div className="name">{props.name}</div> <div className="role">{props.role}</div> <div className="email">{props.email}</div> <button className="button">View Profile</button> </div> ); } // Use it 3 times with different data <ProfileCard name="John Doe" role="Developer" ... /> <ProfileCard name="Jane Smith" role="Designer" ... /> <ProfileCard name="Bob Johnson" role="Scientist" ... />

2️⃣ Easy to Update

Want to change the button? Change it ONCE in the component!

All 3 cards update automatically! No copy-paste needed!

// Change button in ONE place <button className="button"> View Profile 👁️ {/* ← Add emoji here */} </button> // All cards get the emoji automatically! ✨

3️⃣ Super Reusable

Need the same card on another page? Just import it!

Need 100 cards? Still just ONE component definition!

// In another file, just import and use! import ProfileCard from './ProfileCard'; <ProfileCard name="Alice" ... /> <ProfileCard name="Charlie" ... /> // As many as you want!

4️⃣ Clean & Organized

Each component is a separate, self-contained piece.

Easy to understand. Easy to test. Easy to maintain!
